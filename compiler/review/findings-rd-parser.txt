The token parser and the line walker agree. There is no fallback. `parseSpeck` is `parseSpeckDocument`, and that function returns the token parser's result. `compiler/src/__tests__/walker-vs-rd.test.ts` and `compiler/src/__tests__/parser-malformed.test.ts` run both parsers.

| Input | Line walker | Token parser | Test |
| --- | --- | --- | --- |
| every `examples/*.speckdl` and every `.speckdl` fixture | IR from `lower()` | the same IR | lowers every example and fixture to the same IR |
| empty file and a comment-only file | IR | the same IR | lowers every example and fixture to the same IR |
| `speck A {` with no close | `missing final "}"` at `bad.speckdl:1` column 9 | the same message | rejects a missing close |
| extra `}` | `extra "}"` at line 3 column 1 | the same message | rejects an extra close |
| `} junk` | `text after a speck's "}"` at line 2 column 3 | the same message | rejects text after a close |
| `garbage line here` | `unrecognized member "garbage line here"` at line 2 column 5 | the same message | rejects an unrecognized member |
| `§` | `unexpected character "§"` at line 2 column 2 | the same message | rejects a section sign |
| `y Nat` | `unrecognized state field "y Nat"` at line 2, no column | the same message | rejects an unrecognized state field and an unrecognized init line, without a column |
| `y = 0` | `unrecognized init line "y = 0"` at line 3, no column | the same message | rejects an unrecognized state field and an unrecognized init line, without a column |
| unterminated `"` | `unterminated string (column 8)` | the same message | reports an unterminated string with the column |
| a well-formed action whose string contains `}` | the AST | `JSON.stringify` of the same AST | does not treat a brace inside a string as an extra close |

`walker-vs-rd.test.ts` also compares the error text for `→`, `speck` with the name on the next line, a second speck on one line, code after `*/`, text after a member `}`, a misspelled member, a misspelled top-level name, and `speck 9A`. The messages are equal. When both accept, `JSON.stringify` of the ASTs is equal.
